04 / 08
Стандарт

AES (FIPS-197)

  • Симметричный блочный шифр.
  • Размер блока: 128 бит.
  • Длина ключа: 128 / 192 / 256.
Режим

CBC + PKCS#7

  • CBC связывает блоки шифротекста.
  • PKCS#7 — выравнивание длины.
  • Ключ: SHA-256(фраза), усечение.
05 / 08 Протокол

Вектор инициализации (IV)

  Пакет = Base64( IV ‖ Ciphertext )
           └─ 16 B ─┘   └─ перем. ─┘

  • IV случайный (os.urandom) или задан вручную
  • Тот же открытый текст + другой IV → другой пакет
  • IV не секрет — передаётся с шифротекстом
  • При decrypt IV читается из первых 16 байт

07 / 08 Демонстрация

Сценарий показа

  1. Вкладка «Шифрование»: фраза, ключ 256, запуск конвейера → пакет Base64.
  2. Инспектор: режим, IV, размер пакета.
  3. «Расшифровка»: тот же ключ → восстановление текста.
  4. Тест неверного ключа — ожидаемая ошибка.
